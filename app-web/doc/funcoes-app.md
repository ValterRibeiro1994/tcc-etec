# Funções do Sistema

[ ] Enviar E-mail para órgãos públicos
    - O Sistema deve gerar um E-mail com os dados da denúncia.
    - O sistema deve reenviar toda semana os e-mails que não tiveram o caso resolvido.

[ ] O usuário deve criar uma denúncia.
    - enviar fotos e vídeos da denúncia, o endereço do fato.

[ ] O usuário acompanha o status da denúncia.
    - O sistema espera a resposta do órgão respónsavel, e envia um E-mail para o usuario.
    - O usuário pode escrever sobre o processo (Liguei para o órgão e eles me disseram etc..)

[ ] O usuário pode buscar denúncias por região, por orgão competente, por denúncias resolvidas e etc.
    - "Conforme o projeto for andando podemos encontrar outras necessidades de filtros diferentes"

[ ] Compartilhar denúncias e pedir apoio
    - O usuário deve compartilhar suas denúncias com outras rede sociais.

[ ] O sistema deve informar quais são os órgãos responsaveis para suas denuncias.
    - O sistema deve manter esses dados.
    - O sistema deve indentificar o órgão pelo problema relatado
